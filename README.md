# homebrew-tap

Homebrew tap for [extendo](https://extendo.poob.me) — a free, lightweight menu bar
clipboard history manager for macOS with end-to-end encrypted iCloud sync.

## Install

```sh
brew install tjq/tap/extendo
```

## Upgrade

```sh
brew upgrade extendo
```

Release artifacts attached to this repo's [Releases](https://github.com/tjq/homebrew-tap/releases)
are signed with a Developer ID certificate and notarized by Apple.
